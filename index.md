## Paint night workflow

1. Photo the minis (for the site) and diary page (keep offline)
2. Add or update a file in `entries/` with `faction:` matching a key in `_data/factions.yml`
3. Drop **model photos only** in `assets/photos/` - `{entry_slug}_{DDMMYYYY}.jpg`
4. Set `finished:` when you have a finished shot
5. Commit, push - site rebuilds in a minute or two
